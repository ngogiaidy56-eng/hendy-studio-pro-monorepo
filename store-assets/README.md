# Store & Release Asset Kit

This folder contains **templates**, not approved store assets or signed installers. Replace placeholders and validate every statement against the shipped build.

- `STORE_LISTING_VI.md`: Vietnamese marketing copy, platform requirements, and privacy declarations to verify.
- `RELEASE_CHECKLIST.md`: release and store submission checklist.
- `hendy-app-icon.svg`: editable vector logo concept. Convert to each store's required raster dimensions and test at small sizes.
- `feature-graphic-template.svg`: generic feature-graphic layout; replace text/imagery and export to each platform's exact current dimensions.

Before publishing: remove sample/fictitious metrics, complete public legal/support pages, inspect third-party SDK/data collection, generate genuine screenshots of the released application, sign artifacts and obtain store review.
